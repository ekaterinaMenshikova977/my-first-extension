## Название плагина - *Count Words*

### Описание плагина 

*Count Words* - расширение для Visual Studio Code, предназначенное для подсчёта количества слов в открытом текстовом документе.

Расширение разработано на языке TypeScript с использованием VS Code Extension API.

### Возможности

1. Корректный подсчет слов в открытом текстовом документе
2. Проверка на отсутствие слов в файле
3. Проверка наличия открытого текстового редактора
